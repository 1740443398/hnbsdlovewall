# 抽奖模块 · 管理员操作手册

> 适用版本：当前主分支（含参与条件校验 / 提醒 / 推送 / 看板 / 日历）
> 入口：后台 →「抽奖管理」(`/admin/lottery.php`)

---

## 1. 界面总览

| 区块 | 作用 |
|---|---|
| 数据概览（统计卡） | 抽奖总数 / 进行中 / 已开奖 / 参与人次 / 提醒人次 / 中奖人数 / 浏览总数 / 参与转化 / 分享浏览 / 分享参与 |
| 参与转化漏斗 | 浏览 → 参与 → 提醒 → 中奖 四段转化，宽度以浏览为基准 |
| 抽奖日历 | 按月看排期；手机端自动降级为按日列表；**点空白日期可预填创建表单的开奖时间** |
| 创建抽奖 | 模板起手 + 表单填写 |
| 抽奖列表 | 筛选（全部/进行中/已开奖）、排序（最新/参与人数/开奖时间）、单条操作 |

---

## 2. 创建抽奖

1. 选「快速模板」（可选）：点赞抽奖 / 转发抽奖 / 学习打卡 / 期中加油
2. 填标题、奖品、中奖名额、开奖时间
3. 上传封面（可选，≤3MB，jpg/png/gif/webp；选完即时预览，可移除）
4. 写说明（领奖方式等）
5. 勾选「参与方式」：

| 规则 | 是否自动核验 | 说明 |
|---|---|---|
| 关注发起人 | ✅ | 参与者需关注你 |
| 点赞 | ✅ | 需给「附带动态」点赞（未绑定动态时仅提示） |
| 评论 | ✅ | 需在附带动态下评论 |
| 转发 | ✅ | 需发一条引用附带动态的动态 |
| 自定义条款 | ❌ 仅提示 | 如「需为本校学生」，参与者需勾选「我已知晓」才能参与 |

> 可核验规则会在前台显示 ✓/✗，未完成可一键跳「补全页」原地完成。

---

## 3. 编辑 / 复制 / 删除

| 操作 | 位置 | 说明 |
|---|---|---|
| 编辑 | 列表「编辑」 | 改标题/奖品/名额/开奖时间/说明/规则/封面；进行中的抽奖时间必须晚于现在 |
| 复制 | 列表「复制」 | 沿用配置生成「原标题（副本）」，开奖时间按原活动时长顺延（最少 24h） |
| 删除 | 列表「删除」 | **需输入活动标题原文确认**；参与记录一并清除 |

---

## 4. 开奖

- 到点自动开奖（有人访问抽奖页时触发）；也可「立即开奖」
- 开奖前弹确认框，明确「不可撤回 / 不可重新抽选 / 不会再新增参与」
- 开奖后：
  - 站内通知发给提醒订阅者（中奖/未中奖文案不同）
  - App 推送队列写入两条：中奖者「🎉 恭喜中奖：标题（含奖品×数量）」、未中奖者「🎁 抽奖开奖：标题（含奖品×数量）」
  - 参与者可在详情页看中奖名单，中奖者有一键「恭喜」按钮

---

## 5. 群发私信给参与者

列表每条抽奖下方：

1. 看「群发范围：全部 N 人 · 中奖 M 人 · 未中 K 人」预览
2. 选范围：全部参与者 / 仅中奖者 / 仅未中奖
3. 填写内容，可用变量：`{title}` `{prize}` `{prize_count}` `{draw_at}`
4. 二次确认后发送；自动跳过无 QQ / 自己 / 被封禁账号
5. 结果提示「已发送 N 条私信，跳过 M 人」

---

## 6. 导出复盘 CSV

列表「导出 CSV」→ `/admin/lottery_export.php?id=X`

包含：概况（规则/浏览/分享浏览/参与/提醒/中奖人数）+ 名单（昵称/QQ/是否中奖/来源/参与时间），UTF-8 BOM，Excel 直接打开不乱码。

---

## 7. 推送与通知排查

- 推送历史：`/admin/app_push.php`
- 从抽奖列表点「推送记录」可直接带 `?lot=ID` 定位该抽奖的推送
- App 推送为**轮询制**（最短约 15 分钟），不是即时；即时提醒走站内通知面板
- 用户可在抽奖详情页点「🔔 推送已开 / 🔕 推送已关」自行关闭抽奖推送

---

## 8. 用户侧参与路径（便于答疑）

```
看到抽奖 → 规则芯片 ✓/✗ → （缺条件）一键补全页：关注/点赞/评论/转发原地完成
→ 进度条 N/M → 全部完成自动返回 → 自定义条款勾选 → 参与
→ 设「提醒我」→ 开奖前 10 分钟站内+推送提醒 → 开奖通知 → 中奖名单/恭喜
→ 分享：复制带 from=share 的链接 或 生成海报（含二维码）
```

---

## 9. 常见问题

**Q：为什么有人没关注也能参与？**
检查规则数组里是否有「关注」；旧数据可能只有 rule_like 等布尔字段，用编辑页重新勾选保存即可。

**Q：开奖了才发现奖品写错？**
开奖不可撤回；可「复制」一条新活动修正后发布，并群发私信说明。

**Q：推送没弹？**
1) 用户是否关闭了抽奖推送；2) App 是否在后台且有轮询权限；3) 推送历史里是否已有记录（有记录=已入队，非投递失败）。

**Q：分享来源数据怎么涨的？**
通过海报二维码或 `?from=share` 链接进入计「分享浏览」；由此参与计「分享参与」。

## 10. 数据文件（data/）

| 文件 | 内容 |
|---|---|
| `lotteries.json` | 抽奖主体（rules/views/share_views/pre_notified…） |
| `lottery_entries.json` | 参与记录（含 via=manual/share） |
| `lottery_reminders.json` | 开奖提醒订阅 |
| `lottery_push_off.json` | 关闭抽奖推送的用户 |
| `app_pushes.json` | App 推送队列 |
| `notifications.json` | 站内通知（type=lottery_result） |

备份/迁移时以上文件需一起带走。
