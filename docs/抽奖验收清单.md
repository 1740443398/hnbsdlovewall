# 抽奖模块 · 验收清单

> 目的：发布前快速确认抽奖链路完好。自动化部分已脚本化，手工部分按清单勾选。

---

## A. 自动化冒烟（必须通过）

```bash
php tools/lw_lottery_smoke.php
```

期望输出：`PASS=13 FAIL=0`，覆盖：

| # | 检查点 |
|---|---|
| 1 | 创建抽奖 + rules 数组（含自定义条款）落库 |
| 2 | 点赞规则未完成时参与被拒（绑定动态场景） |
| 3 | 点赞后可参与、重复参与被拒 |
| 4 | 提醒订阅、推送开关生效 |
| 5 | 开奖成功并产生 App 推送 + 站内通知 |
| 6 | 编辑抽奖配置成功 |
| 7 | 临时数据自动清理 |

> 脚本会在 data/ 中创建临时记录并自动删除，**不要在生产环境运行**。

## C. 前台手工验收（30 分钟）

| 步骤 | 操作 | 期望 |
|---|---|---|
| C1 | 打开抽奖列表 | 筛选（全部/我参与的）、状态、排序、分页都可切换且保留参数 |
| C2 | 打开进行中抽奖详情 | 规则芯片显示 ✓/✗；缺条件时按钮显示「还差 N 项条件」，旁边有「一键补全 →」 |
| C3 | 进入补全页 | 进度条 N/M 正确；关注/点赞/评论/转发可原地完成；全完成自动返回 |
| C4 | 含自定义条款的抽奖 | 勾选「我已知晓」后参与按钮才可用 |
| C5 | 参与成功 | 页面刷新为「已参与 ✓」，可设置提醒/复制链接/生成海报 |
| C6 | 生成海报 | 弹层出图，二维码可扫，保存 PNG 成功 |
| C7 | 分享链接 | 复制出的 URL 带 `from=share`，打开后详情正常 |
| C8 | 开奖后详情 | 显示中奖名单；中奖者有「恭喜」按钮；「我参与的」显示已中奖 |
| C9 | 通知面板 | 「🎁 抽奖」分类有开奖通知，未读计数正确 |

## E. 回归关注点

- 开奖不可逆：抽奖一旦 drawn，前端不可再参与
- 删除时同步清理：lottery_entries / lottery_reminders / 关联 post 的 lottery_id
- 推送上限：app_pushes 500 条、设备台账 3000 条（既有逻辑）
- 关闭推送的用户不得再收到抽奖推送（lottery_push_off 生效）
