### AI 助手
- 站内 AI 助手「小墙」，默认由智谱 **GLM-4.1V-Thinking-Flash** 驱动（API 密钥仅存于服务端，绝不下发前端）
- **全站全页面可用**：右下角悬浮小助手，任意页面（含登录页、错误页、后台）都能唤起；`pages/ai_assistant.php` 是它的完整版页面，两处共用同一套渲染核心与会话存储
- **懂站内数据**：按提问意图实时读取站点概况、公告、最新/热门帖子、**周榜/月榜热榜**、帖子详情与评论、关键词搜索、分类统计、活跃榜、用户公开资料、我的帖子/收藏/评论/通知/私信摘要/签到/关注、签到榜、功能投票、赞助与头衔、客户端版本、天气与一言（数据面约 26 类意图）
- **发帖页智能成稿**：发帖时用一句话说明要点（失物、求助、表白……），自动整理成标题与正文；素材里没有的地点、联系方式等一律不编造，已有内容会先征求同意再替换
- **有人情味**：人设定位为「靠谱的学长/学姐」，覆盖学习辅导（九科 + 作文/背诵/考试心态/时间规划）与生活陪伴（作息/情绪/人际/亲密关系/家庭沟通），并对情绪困扰给出认真的危机干预引导
- **会给出站内链接**：回复里的站内路径渲染成可点链接；外链一律渲染为不可点文本 + 「外部」徽标，不让 AI 成为钓鱼跳板
- **确认卡片式代办**：收藏/取消收藏、点赞/取消点赞、关注/取关、每日签到、给帖子投票、标记通知已读、发表评论、删除自己的帖子或评论、**发帖、发私信** —— AI 只会「生成一张待确认卡片」，必须用户点「确认执行」才真正落库（共 14 个动作）
- **游客只读**：未登录也能问公开内容与学习生活问题；涉及个人数据与写操作时引导注册登录
- **安全设计**：卡片参数只存服务端会话、前端仅持不透明 token（改不了参数）、token 一次性 + 10 分钟过期、发卡节流、业务级限流、审计日志；改密码/改绑 QQ/开关 2FA/退出登录/举报/申请头衔/一切管理员操作**明确禁止** AI 代办
- **防注入**：注入模型上下文的用户内容（帖子标题正文、评论、昵称）先经沙箱化处理（中和 `<lw-action>` 协议标签、剥离 Markdown 链接地址、替换裸 URL），并明确声明「数据≠指令」

#### 高级选项 · 用户接入自己的 AI

站点提供三组按钮的配置面板（AI 浮窗 →「高级选项 · 接入我自己的 AI」）：

| 按钮 | 行为 |
|---|---|
| 测试连接 | 用刚填的或已保存的配置发一次最小请求，验证能不能通 |
| 保存 | 写入配置（API Key 留空 = 沿用已保存的那把） |
| 一键还原 | 删掉自己的配置，回到站点默认模型 |

可配置：接口地址（端点白名单校验，防 SSRF）、模型名、API Key、自定义系统提示词等。

三条硬规则：

1. **密钥绝不回传明文** —— 前后端之间只走脱敏值（只回末 4 位），明文只在服务端内存里存在一瞬；落盘为**密文**。
2. **必须登录** —— 游客没有「自己的 AI」这回事。
3. **一键还原只删自己那条记录** —— 不触碰站点配置，也不影响别人。

自配的 AI 与站点默认模型**共用同一套内核**，因此同样拥有完整站内读写权限（14 个确认卡片动作全部可用），并非降级体验。

## 技术栈

- **后端**：纯手写 PHP 8.4（无框架、无 Composer）
- **存储**：JSON 文件存储（无数据库）
- **前端**：原生 JavaScript + CSS3（无构建链；可选压缩脚本见下）
- **字体**：Inter / Noto Sans SC
- **第三方集成**：智谱 AI（GLM）、SMTP（QQ 邮箱）
- **安全**：自定义 WAF、CSP、CSRF、频率限制

## 环境要求

- **PHP 8.0 或更高**（开发与线上均为 PHP 8.4；代码本身未使用 PHP 8 专属语法，但未在 7.x 上做过完整验证）
- 需要扩展：`curl`、`mbstring`、`json`、`gd`、`openssl`（缺 `curl`/`mbstring` 时 AI 助手等部分功能不可用，其余功能正常）
- 支持 PHP 的 Web 服务器（Apache/Nginx），或直接用 PHP 内置服务器
- `data/`、`uploads/` 目录需有写入权限

### 快速本地运行

项目根目录下的 `启动.bat`（Windows）会：检测 PHP 与必需扩展 → 缺 PHP 时自动从国内镜像下载便携版 → 选一个空闲端口 → 检测公网地址并询问是否使用 → 拉起内置服务器并自动打开浏览器。

- 脚本会**保持窗口打开**；要停止服务请按提示**输入 `Q` 再回车**（直接关闭窗口同样会停服）。
- 该脚本为 **GBK 编码**（中文 Windows 的默认代码页），修改时请勿另存为 UTF-8。

1. 将所有文件上传到Web服务器
2. 确保 `data/`、`uploads/` 目录可写（或由 `.htaccess` 保护）
3. 在浏览器访问一次 `init.php`（例如 `https://你的域名/init.php`）以生成默认超级管理员账号
4. 默认超级管理员账号：
   - **用户名**：`admin`
   - **密码**：`admin`
5. **安全提醒**：使用 `admin`/`admin` 登录后，请立即在安全/改密页面修改默认密码。该账号被标记为首次登录必须改密。
6. 初始化后站点即可使用，直接访问站点根路径（`index.php`）即可。

### 部署到线上站点时，**不要**上传这些内容

只上传程序代码（`admin/`、`api/`、`assets/`、`config/*.php`（不含密钥的那几个）、`includes/`、`lang/`、`pages/`、`licenses/`、`tools/`、`index.php`、`init.php`、`sitemap.php`、`sw.js`、`offline.html`、`manifest.webmanifest`、`.htaccess`、`robots.txt`），下列内容属于本机数据或敏感凭据：

- `data/`（全站 JSON 数据：用户、帖子、私信、日志）
- `uploads/`（用户上传的图片）
- `config/ai_config.php`、`config/mail_config.php`、`config/sync_config.php`（含 API Key / 邮箱密码 / 同步种子，**一旦泄露请立即更换**）
- `config/sync_nonces.json`（防重放记录，运行期生成）
- `keystore.properties`、`*.jks`、`*.keystore`（安卓签名密钥，**绝不外传**）
- `.shots/`、`.idea/`、`.trae/`、`node_modules/`、`*.log`、`*.bak`、`love_wall.zip`
- `data_backup_*/`（本地备份目录）

到达服务器后，在浏览器访问一次 `init.php` 生成默认超级管理员，并立即修改默认密码。

> `config/app_config.php` 如含真实 APK 文件名与 SHA-256，**不含密钥，可以上传**（上传后站内「安装应用」与 App「检查更新」才能正常工作）。

## 数据同步工具（`tools/`）

站长/开发者可在本机直连站点的前提下，绕过邮件验证码流程，直接拉取或写回全站 JSON 数据。

| 文件 | 用途 |
|---|---|
| `tools/lw-sync-key.ps1` / `lw-sync-key.bat` | 查看当前同步密钥与有效期，并生成可直接在浏览器打开的**一次性签名链接**（线上 / 本地各一条） |
| `tools/lw_sync_pull.php` / `lw-sync-pull.bat` | 从线上 `/api/ai_sync.php` **拉取全量数据并覆盖本地 `data/`** |

鉴权用 `config/sync_config.php` 里的 HMAC 种子（自动生成、90 天轮换），请求不传输种子本体：

```
X-Sync-Timestamp: <Unix 秒>
X-Sync-Key:       hex(HMAC-SHA256(种子, 规范串))
规范串 = 时间戳 \n 方法 \n 路径 \n sha256(请求体)
```

签名**只能用一次**（服务端防重放），时间戳偏差需在 ±300 秒内。

```bash
# 先预览将写入哪些表，不落盘
php tools/lw_sync_pull.php --dry-run

# 确认后实际覆盖写入
php tools/lw_sync_pull.php
```

> 注意：`lw_sync_pull.php` 会**覆盖覆盖目标的所有表**（含日志与限流记录）。运行前请确认目标副本，必要时先备份 `data/`。
>
> 另外，站点宿主机带有 JS 反爬挑战，工具已内置自动过挑战逻辑，无需人工干预。

## 静态资源压缩（可选）

项目无构建链，`assets/` 下的 `.js` / `.css` 直接可读可改，`.min.*` 是派生产物。

```bash
bash tools_build_assets.sh           # 只压缩「源文件比 .min 新」的
bash tools_build_assets.sh --force   # 全部重压
```

需要 Node.js 与 `terser`、`clean-css-cli`：

```bash
npm i --prefix .buildtools terser clean-css-cli
```

服务端 `asset_url()` 会在「`.min` 存在且不比源旧」时输出 `.min`，否则自动回退源文件 —— 所以**忘记跑压缩脚本最多损失体积，绝不会把旧逻辑发上线**。上传时记得把 `.min.*` 一起传（线上没有 Node）。

另有可选的**混淆加固模式**，用于上线前手工加固（默认关闭，不影响日常压缩）：

```bash
# 域名锁 + 防篡改包装，仅作用于 4 个入口 JS（仅当 LW_ALLOWED_HOSTS 非空才生效）
LW_ALLOWED_HOSTS=hnbsd.ct.ws bash tools_build_assets.sh --force --obfuscate
```

绝不 mangle 属性名（`mangle.properties=false`），保护与后端约定的 JSON 字段、DOM `class`/`id` 与 `window.X` 全局。完整设计与回归见 [tools_obfuscate_readme.md](tools_obfuscate_readme.md)。

## 注意事项

- 本项目使用 JSON 文件存储数据，无需 MySQL 或其他数据库
- 所有数据存储在 `data/` 目录中，图片存储在 `uploads/` 目录
- `data/*.json` 采用**紧凑格式**（不缩进）写入，以节省共享主机的磁盘配额并加快 `json_decode`
- 多语言支持（简体中文、繁体中文、英文）；自动检测语言，可在顶部语言切换器手动切换（存于 Cookie）
- 含密钥的配置文件（`config/mail_config.php`、`config/sync_config.php`、`config/ai_config.php`）**不纳入版本控制**，请自行填写自己的凭据；未配置时 AI 助手会优雅降级
- 所有发往用户的邮件均附上本站网址
- 本项目设计用于共享主机部署（如 InfinityFree）
