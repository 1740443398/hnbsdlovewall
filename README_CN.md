## 功能列表

### 核心社交功能

- 匿名发帖支持

- 评论系统（支持点赞）
- 帖子点赞与收藏
- 投票系统
- 帖子关键词搜索

## 技术栈

- **后端**：PHP 7.4+
- **存储**：JSON文件存储（无需数据库）
- **前端**：原生JavaScript、CSS3
- **字体**：HYWenHei（原神风格字体）
- **安全**：自定义WAF、CSP、CSRF、频率限制

## 环境要求

- PHP 7.4 或更高版本
- 支持PHP的Web服务器（Apache/Nginx）
- `data/`、`uploads/`、`music/` 目录需有写入权限

## 安装指南

1. 将所有文件上传到Web服务器
2. 确保 `data/`、`uploads/`、`music/` 目录可写（或由 `.htaccess` 保护）
3. 在浏览器访问一次 `init.php`（例如 `https://你的域名/init.php`）以生成默认超级管理员账号
4. 默认超级管理员账号：
   - **用户名**：`admin`
   - **密码**：`admin`
5. **安全提醒**：使用 `admin`/`admin` 登录后，请立即在安全/改密页面修改默认密码。该账号被标记为首次登录必须改密。
6. 初始化完成后站点即可使用。后续访问走正常入口（`router.php` 或虚拟主机配置）。

## 配置说明

编辑 `config/constants.php` 可自定义：
- `SITE_NAME` - 站点名称
- `SUPER_ADMIN_QQ` - 超级管理员QQ号
- `BCRYPT_COST` - 密码哈希强度
- `SESSION_LIFETIME` - 会话有效期
- `ITEMS_PER_PAGE` - 每页帖子数

## 注意事项

- 本项目使用JSON文件存储数据，无需MySQL或其他数据库
- 所有数据存储在 `data/` 目录中
- 音乐文件请放置在 `music/` 目录（支持MP3、WAV、OGG、M4A、AAC、FLAC格式）
- 上传的图片存储在 `uploads/` 目录
- 本项目设计用于共享主机部署（如InfinityFree）
